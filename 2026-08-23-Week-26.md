## Topics Studied

### Module 15 – Securing Windows

Module 15 focused on securing Windows systems and controlling how users authenticate and access resources.

Some of the main areas I worked through included:

* Logical security and access control
* Vulnerabilities, threats, and risk
* Symmetric and asymmetric encryption
* Cryptographic hashing
* Digital signatures
* Windows user accounts and groups
* User Account Control (UAC)
* Authentication methods and MFA
* Windows Hello
* Single Sign-On and SAML
* Windows domains and Active Directory
* Organizational Units
* Group Policy
* Windows file and printer sharing
* NTFS and share permissions
* Permission inheritance
* Domain accounts and user data

One of the most useful parts of this module was seeing how different Windows security technologies work together.

Authentication establishes who a user is, authorization determines what that user can access, groups make permissions manageable, and technologies such as UAC, Active Directory, and Group Policy extend those controls across Windows environments.

The sections covering **NTFS and share permissions** were particularly useful because file access can depend on several overlapping factors, including group membership, inheritance, explicit permissions, and whether a resource is being accessed locally or across a network.

---

### Module 16 – Installing Operating Systems

Module 16 focused on installing, upgrading, deploying, and recovering operating systems.

Some of the main areas included:

* Windows editions and licensing
* 32-bit vs. 64-bit Windows
* Windows Home, Pro, Enterprise, and Education
* Workgroups vs. domains
* Windows Pro and Enterprise features
* Windows upgrade paths
* TPM 2.0
* UEFI and Secure Boot
* Feature and quality updates
* Clean installations vs. in-place upgrades
* Hardware and software compatibility
* Unattended installations
* System image deployment
* Network and zero-touch deployment
* Installation media and boot devices
* PXE and network boot
* Multiboot systems
* Disk partitioning
* MBR vs. GPT
* File systems
* Windows repair and recovery options

This module reinforced that installing an operating system involves much more than simply creating a bootable USB drive and running an installer.

A technician needs to consider **hardware requirements, firmware, drivers, applications, licensing, backups, partitioning, file systems, security requirements, and the appropriate installation or deployment method** before beginning the process.

I also found the enterprise deployment material particularly interesting. Technologies such as unattended installations, system images, PXE, network installations, and zero-touch deployment demonstrate how the same basic installation process can be scaled across large numbers of systems.

## Key Takeaways

The biggest theme for me this week was **centralized Windows administration**.

Module 15 showed how identity, authentication, permissions, Active Directory, and Group Policy work together to manage users and computers securely across an organization.

Module 16 then expanded that idea into operating system deployment. Installing Windows manually on one computer is relatively straightforward, but supporting an organization requires methods for deploying and configuring systems consistently and efficiently.

I also have a much better understanding now of how technologies such as **TPM, Secure Boot, UEFI, GPT, BitLocker, Group Policy, Active Directory, and PXE** fit into a modern Windows environment.

Rather than seeing them as individual A+ exam objectives, I am starting to see how they connect to the process of deploying, securing, and supporting actual Windows computers.

That connection between the certification material and real IT support work is something I want to continue developing.
