# Weekly Cybersecurity Journal – Week 32

## Overview

This week continued the final preparation phase for the **CompTIA A+ Core 2 exam**.

Most of my study time was again spent completing practice questions, reviewing incorrect answers, and revisiting topics where I still need more confidence.

At this stage, the preparation process is becoming increasingly focused.

Instead of studying entire modules again, I am using practice tests to identify specific gaps and then reviewing those areas individually.

I have also started thinking more seriously about what comes **after CompTIA A+**.

The certification is an important foundation, but the next objective will be turning that knowledge into practical IT skills and experience.

---

## Exam Preparation

Practice exams remained the main focus this week.

The questions continue to cover material from across Core 2, particularly:

* Windows troubleshooting
* Administrative tools
* Malware and security
* Authentication
* System performance
* Storage
* Mobile devices
* Networking
* Operational procedures

One area I have continued working on is distinguishing between tools that appear similar but are designed for different purposes.

For example, troubleshooting questions may require choosing between utilities for monitoring performance, examining network connections, modifying boot configuration, cleaning storage, or managing Windows settings.

Knowing the definition of each tool is not always enough.

The important skill is being able to look at a problem and determine **which tool is appropriate for that particular situation**.

This is becoming one of the main benefits of working through large numbers of practice questions.

## Preparing for the Next Stage

Alongside exam preparation, I have started researching the equipment I will use for the next stage of my IT studies.

One of my priorities after completing A+ is to move into more **hands-on practical work**.

I have therefore been researching laptops that could serve as a dedicated system for IT labs and future projects.

Rather than looking only at general specifications, I have been considering what will actually matter for the type of work I want to do, including:

* RAM capacity
* Storage
* Processor performance
* Virtualization support
* Upgradeability
* Reliability
* Running multiple virtual machines

The goal is to have a system capable of supporting practical environments involving technologies such as:

* Windows administration
* Active Directory
* Windows Server
* Microsoft 365
* Linux
* Networking
* Virtual machines
* Security tools

This research has been useful because it connects hardware concepts from A+ with a real purchasing decision.

A laptop for this purpose is not simply an everyday computer.

It will eventually become a **portable IT lab**.

## Key Takeaways

The biggest takeaway this week is that I am beginning to transition between two stages of my learning.

The first stage has been about building the foundation:

**Study → Understand → Practice → Certification**

The next stage will increasingly become:

**Build → Configure → Break → Troubleshoot → Document**

CompTIA A+ has given me exposure to a large number of technologies and troubleshooting concepts.

The next challenge will be applying those concepts in practical environments rather than only answering questions about them.

For now, however, the priority remains finishing what I started.
