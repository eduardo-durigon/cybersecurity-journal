### Windows Administration

A large portion of the module explored the different ways Windows can be configured and administered.

I learned more about:

* Windows Settings and Control Panel
* Administrator and standard user accounts
* Local and Microsoft accounts
* Windows Hello authentication
* User Account Control (UAC)
* Privacy settings
* Accessibility features
* File Explorer

Understanding the differences between administrator and standard user accounts reinforced how Windows protects systems from accidental or malicious changes. Features such as User Account Control provide an additional layer of security by requiring administrator approval before allowing applications to make system-wide modifications.

The module also provided a better understanding of the Windows file structure and how important folders such as **Program Files**, **Users**, and **System32** are organised within the operating system.
