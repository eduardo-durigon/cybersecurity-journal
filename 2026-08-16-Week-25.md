# Weekly Cybersecurity Journal – Week 25

## Topics Studied

Module 13 focused on configuring and managing Windows systems.

Some of the main areas I worked through included:

- Windows editions and features
- Windows installation and upgrade methods
- Windows settings and configuration
- Storage and file systems
- Windows networking

### Module 14 – Supporting and Troubleshooting Windows

Module 14 shifted the focus from configuring Windows towards **monitoring, supporting, recovering, and troubleshooting Windows systems**.

Some of the main areas included:

- Remote support
- System Information and Event Viewer
- Task Manager
- Resource Monitor and Performance Monitor
- CPU, memory, disk, and network monitoring
- Startup applications and Windows services
- Windows boot processes
- Safe Mode and Windows Recovery Environment
- System Restore and restore points
- Driver and update rollback
- Windows recovery and reinstallation
- Boot failures and black screens
- Performance troubleshooting
- BSOD and system instability
- USB troubleshooting
- Application and service failures

The troubleshooting sections were particularly useful because they brought together many Windows tools that I had previously studied individually.

Rather than simply knowing what each utility does, the focus was increasingly on understanding **which tool to use, what information to look for, and how that information helps identify the cause of a problem**.

## Key Takeaways

The biggest adjustment this week has been the **amount of material in Core 2**.

The modules feel longer and more detailed than what I experienced during Core 1, but I do not want that to change the way I approach the certification. My priority is still understanding the material properly rather than trying to finish it as quickly as possible.

Another major takeaway has been how interconnected Windows troubleshooting tools are.

Task Manager, Event Viewer, Resource Monitor, Performance Monitor, Safe Mode, System Restore, and Windows Recovery Environment are not isolated utilities. They provide different pieces of information or different levels of recovery depending on the problem.

Module 14 especially reinforced the importance of identifying the **failure point and symptoms first**, gathering evidence, and only then deciding on the appropriate solution.

That troubleshooting mindset is something I want to continue developing beyond simply passing the A+ exam.
